# 🎯 PeaShooter

**PeaShooter** is a roguelike shooter developed using Unity's Data-Oriented Technology Stack (DOTS). The game features a modular ability system, a performant Entity Component System (ECS) architecture, and predictive physics targeting. It also integrates Unity's UI Toolkit for overlays such as ability selection, leveling, and pause interactions. Collision and damage systems are implemented following DOTS best practices.

## 🚀 Features

- **Modular Ability System**: Design and integrate new abilities with ease.
- **ECS Architecture**: Leverages Unity's DOTS for high-performance gameplay.
- **Predictive Physics Targeting**: Implements advanced targeting mechanics.
- **UI Toolkit Integration**: Seamless overlays for various game interactions.
- **Collision & Damage Systems**: Robust systems built with DOTS principles.
